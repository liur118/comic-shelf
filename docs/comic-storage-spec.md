# 漫画资产存放规范

Comic Shelf 通过扫描本地目录（称为「资源库」）建立漫画元数据。爬取或整理漫画时，必须按本规范存放，否则扫描时会被忽略或排序错乱。

## 1. 目录结构

```
<资源库根目录>/                      ← 在网站中「添加资源库」时填写的路径
├── 海贼王/                          ← 漫画目录，目录名 = 漫画名
│   ├── cover.jpg                    ← 可选，封面
│   ├── 0001 第1话 冒险的黎明/        ← 章节目录，目录名 = 章节名
│   │   ├── 001.jpg                  ← 图片，按文件名序号排列
│   │   ├── 002.jpg
│   │   └── 003.webp
│   └── 0002 第2话 戴草帽的路飞/
│       ├── 001.jpg
│       └── ...
├── 火影忍者/
│   └── ...
└── 某短篇/                          ← 不分章：图片直接平铺在漫画目录下
    ├── cover.jpg                    ← 可选，封面（不计入正文页）
    ├── 001.jpg
    └── 002.jpg
```

两种形态：

- **分章**：资源库 → 漫画 → 章节 → 图片
- **不分章**：资源库 → 漫画 → 图片，整部漫画作为一章（显示为「全一话」）

## 2. 规则

### 2.1 漫画目录

- 资源库根目录下的**每个一级子目录**是一部漫画，目录名即漫画名（原样展示）。
- 目录名不能以 `.` 开头（隐藏目录会被忽略）。
- 漫画目录下既没有有效章节、也没有平铺图片时，该漫画不会入库。

### 2.1.1 分章 / 不分章的判定

- 漫画目录下**存在至少一个含图片的子目录** → 按分章处理，此时漫画目录下平铺的图片（`cover` 除外）**全部忽略**。
- 否则 → 按不分章处理，漫画目录下平铺的图片（`cover` 除外）按 2.4 的规则排序，作为唯一一章。
- 同一部漫画不要混用两种形态。

### 2.2 封面（可选）

- 放在漫画目录下，文件名为 `cover`，扩展名为支持的图片格式之一，如 `cover.jpg`、`cover.webp`。
- 没有封面时，自动使用第一章第一页作为封面。

### 2.3 章节目录

- 漫画目录下的**每个一级子目录**是一章，目录名即章节名（原样展示）。
- 章节按目录名**自然排序**（数字按数值比较，`2` 排在 `10` 前面）。
- **强烈建议**目录名以补零的序号开头：`0001`、`0002` …，后面可接空格和标题，如 `0001 第1话 冒险的黎明`。
  - 只使用整数序号，不要用 `12.5` 这类小数；番外、特别篇按阅读顺序占用一个正常序号，如 `0105 番外 xxx`。
- 章节目录内不再嵌套子目录（嵌套目录会被忽略）。
- 章节目录内没有任何图片时，该章不会入库。

### 2.4 图片

- 章节目录（不分章时为漫画目录）下的图片文件，按文件名**自然排序**作为页序。
- **强烈建议**文件名为补零的纯序号：`001.jpg`、`002.jpg` …，位数按该章最大页数确定，统一使用 3 位即可。
- 支持格式（扩展名不区分大小写）：`.jpg` `.jpeg` `.png` `.webp` `.gif` `.avif` `.bmp`。
- 其他文件（`.txt`、`.json`、`.DS_Store` 等）会被忽略，可放心存放爬虫的附带文件。

## 3. 命名约束

- 漫画名、章节名中避免使用 `/ \ : * ? " < > |`，保证跨平台可用。
- 编码统一使用 UTF-8（macOS / Linux 默认即是）。

## 4. 更新与重新扫描

- 新增或修改了文件后，在网站「资源库」页面点击「重新扫描」即可同步。
- 扫描以**相对路径**识别漫画与章节：
  - 重命名漫画目录或章节目录，会被视为删除旧的 + 新增新的。
  - 不分章的漫画后来改为分章（新建了章节目录），原来的「全一话」会被移除，平铺图片不再显示。
  - 目录被删除后，重新扫描会从数据库移除对应记录。
- 资源库根目录整体移动位置后，需要删除旧资源库并重新添加。

## 5. 爬虫落盘建议

1. 先写入临时目录（如 `0001 第1话.tmp/`），整章下载完成后再重命名为正式目录名，避免扫描到半成品章节。
   - 注意：`.tmp` 后缀的目录仍是普通目录，会被扫描到；如果爬取与扫描可能并发，请将临时目录放在资源库之外，或以 `.` 开头命名（如 `.0001 第1话/`）。
2. 章节序号以源站的章节顺序为准，从 `0001` 开始连续编号。
3. 页码从 `001` 开始连续编号，不要使用源站的原始文件名（通常是哈希值，无法排序）。
